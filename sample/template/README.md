# vaquita

Split the cost of a shared meal or trip. Give it a list of who paid what, and it tells you each person's share and who has to pay whom.

Python 3.9 or later, standard library only.

## Status

Early. Only the split exists, and some of its tests fail. The rest is in `TODO.md`.

## Run the tests

```bash
python3 -m unittest discover -s tests
```
